# AI Agent for PC
![AI Agent Preview](./ImGui.png) 
A simple and lightweight AI agent designed to run directly on a Windows PC.

## Overview

This project provides a straightforward way to launch an AI agent locally. The main goal is to make the setup and startup process as simple as possible.

You don't need to manually run scripts or use a command line to start the agent. Simply launch the `.exe` file and the agent starts automatically.

## Features

* Simple `.exe` launch
* Runs directly on Windows
* Minimal setup
* No command-line interaction required
* Easy to use for beginners
* Designed for local PC use

## How to Run

1. Download the project.
2. Locate the `.exe` file.
3. Double-click the file.
4. The AI agent will start automatically.

## Goal

The goal of this project is to make running an AI agent on a personal computer as simple and accessible as possible.
